# Prime Architecture Decision Records

This directory contains concrete implementation decisions derived from the owner-approved Prime authority.

Rules:

- The Master Plan and accepted supplements remain product/architecture authority.
- ADRs close implementation choices that the authority deliberately left open.
- An ADR may narrow implementation, but may not silently change an authority boundary.
- If implementation evidence contradicts an ADR: preserve evidence, amend deliberately, review, freeze the correction, then resume.

P1 starts with `ADR-0001-P1-SYSTEM-FOUNDATION.md` and the v1 contracts under `docs/contracts/`.
